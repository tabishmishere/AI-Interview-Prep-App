# AI Interview Prep App

An AI-powered Interview Preparation Application that helps users practice technical and behavioral interview questions using AI-generated responses and feedback.

---

## 🚀 Features

- 🔐 User Authentication (JWT-based login/signup)
- 🤖 AI-generated interview questions
- 📝 Answer submission & evaluation
- 📊 Performance tracking
- 🌐 MERN Stack Application
- 🔑 OpenAI API integration

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Axios
- Tailwind / CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

### APIs
- OpenAI API
