# 🤖 AI Interview Prep App

A full-stack AI-powered interview preparation platform built using the MERN stack.  
This application helps users practice technical and behavioral interview questions with AI-generated responses and feedback.

---

## 📌 Project Overview

The AI Interview Prep App is designed to simulate real interview scenarios.  
Users can:

- Register & Login securely
- Practice AI-generated interview questions
- Submit answers
- Receive AI-based feedback
- Track their preparation progress

This project demonstrates full-stack development, authentication, API integration, and cloud database usage.

---

## 🏗️ System Architecture

Frontend (React)  →  Backend (Node/Express)  →  MongoDB Atlas  
                                ↓  
                           OpenAI API  

---

## 🛠️ Tech Stack

### 👨‍💻 Frontend
- React.js
- Axios
- React Router
- Tailwind CSS / CSS

### ⚙️ Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- dotenv

### ☁️ Cloud & APIs
- MongoDB Atlas
- OpenAI API

---

## 🔐 Authentication Flow

- User registers
- Password stored securely
- JWT token generated upon login
- Protected routes use middleware to verify token
